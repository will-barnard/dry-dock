Workbench — CV library

Your master CV, stored as granular items. The tailoring workflow picks the best-fit items for a given job description.

{# ── applications + tailoring (W2) ── #}

Applications

One row per job you're applying to. Paste the job description, then generate a tailored resume — the agent selects the best-fit items from your library and may lightly rephrase bullets to mirror the JD's terminology (truthfully). Each generate is a new version.

Import a resume

Upload a PDF or paste resume text. A worker extracts the items and merges them into your library — it compares against what's already stored and only adds genuinely new entries, bullets, and skills. Safe to run on several resumes over time.
